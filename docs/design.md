## 2. プロジェクト概要

### 2.1 目的

既存の sound-of-sorting を、HTML・CSS・JavaScript を使用した Web アプリケーションへ移植する。
これにより、ローカル環境や特定の実行環境に依存せず、Web ブラウザ上でソートアルゴリズムの動作と音を体験できるようにする。

### 2.2 想定ユーザー

主な利用者は開発者本人とする。そのため、初期段階では以下を優先する。

- 機能の再現性
- ソート処理の視認性
- 音の再生
- 実装・変更・確認のしやすさ
- 過剰なユーザー管理やサーバー機能を持たない構成

### 2.3 対象範囲

- ソート対象データの表示
- ソートアルゴリズムの実行
- ソート処理のアニメーション表示
- ソート処理に応じた音の再生
- 実行、一時停止、停止、リセットなどの操作
- ソートアルゴリズムや速度などの設定
- Web ブラウザ上での動作確認

### 2.4 対象外

- ユーザーアカウント
- データベース
- サーバーサイド処理
- ユーザー設定の永続保存
- 複数ユーザーでの共有機能
- 外部 API との連携
- 高度なアクセス解析
- スマートフォン向けの完全な最適化

## 3. 前提・制約

### 3.1 前提

- 既存の sound-of-sorting の機能を基本的に引き継ぐ
- 実行環境は Web ブラウザとする
- 開発は GitHub Codespaces 上で行う
- 初期版は静的 Web アプリケーションとして構築する
- データは原則としてブラウザ内のメモリ上で管理する
- 外部ライブラリは必要最小限にとどめる

### 3.2 技術構成

| 区分 | 採用技術 |
| --- | --- |
| マークアップ | HTML |
| スタイル | CSS |
| ロジック | JavaScript (ES Modules) |
| 開発環境 | GitHub Codespaces |
| 実行環境 | Web ブラウザ |
| サーバー | 原則不要（静的配信） |
| データ保存 | 初期版では非永続 |

### 3.3 ブラウザ制約

Web ブラウザでは、ユーザー操作なしに音声を再生できない場合がある。
そのため、初回の音声再生前に以下のユーザー操作を必要とする。

- 「開始」ボタンのクリック
- 「音声を有効化」ボタンのクリック
- ソート操作の実行

音声機能には Web Audio API を利用する。既存版は SDL の音声コールバック内で
オシレータを自前でミキシングしているため（第18章参照）、Web 版では
`AudioContext` + `OscillatorNode`/`GainNode`、または `AudioWorklet` による
同等のミキシング処理のいずれかで再現する（第18.6節）。

## 4. 機能要件

既存版から引き継ぐ機能を中心に実装する。既存機能の詳細は第16章、対応関係は第19章に示す。

### 4.1 ソート対象表示機能

ソート対象となるデータを画面上に表示する。

表示内容

- 配列の各要素
- 各要素の値
- 値に対応する棒グラフ
- 現在アクセス中（比較・読み書き）の要素
- 現在交換中の要素
- マーク済み（ソート済みなど）の要素
- 監視中インデックス（既存版の watch 相当）

| 状態 | 表示例 | 既存版の色 |
| --- | --- | --- |
| 未処理 | 通常色 | 白 |
| アクセス中（比較・読み書き） | 強調色 | 赤 |
| 交換中 | 別の強調色 | 赤（2要素同時） |
| マーク済み・ソート済み | 完了色 | 緑 |
| 監視インデックス | 補助色 | シアン等（アルゴリズムが指定） |
| 一時停止中 | 状態を維持 | - |
| エラー | エラー表示 | - |

### 4.2 ソートアルゴリズム実行機能

選択されたソートアルゴリズムに従って配列を並べ替える。
既存版が対応しているアルゴリズムは32種類であり、一覧と移植優先度は第17章に示す。

アルゴリズムごとの処理は、画面描画や音声処理と分離する。

### 4.3 アニメーション表示機能

ソート処理の進行に合わせて配列表示を更新する。

必須動作

- アクセス（比較・読み書き）対象の強調
- 交換処理の表示
- 要素位置の更新
- マーク済み範囲の表示
- 指定速度に応じた処理間隔の変更
- 処理完了時の状態表示

既存版はアルゴリズム実行スレッド内で 1 回の配列アクセスごとに `g_delay` ミリ秒
スリープする方式である（第16.5節）。JavaScript は単一スレッドであるため、
Web 版では以下のいずれかでこれを再現する。

- 方式A: アルゴリズムを **ジェネレータ関数**とし、配列アクセスごとに操作イベントを `yield` する
- 方式B: アルゴリズムを実行して**操作イベント列を一括生成**し、後から再生する

初期実装では方式A（ジェネレータ）を基本方針とする。理由は以下のとおり。

- 既存版のアルゴリズム実装（アクセス時にその場で待つ）と構造が一対一で対応する
- Bogo Sort など、イベント数が事前に確定しない/膨大になるアルゴリズムでもメモリを消費しない
- 一時停止・停止・速度変更を、次イベントの取り出しタイミングで自然に実現できる

操作イベントの型は、既存版の `SortArray` の計測 API（第16.4節）に合わせて次のとおりとする。

```javascript
{ type: "compare", indices: [i, j] }   // 比較（アクセス2回ぶんの音を鳴らす）
{ type: "get",     indices: [i] }      // 読み出し
{ type: "set",     index: i, value: v } // 書き込み
{ type: "swap",    indices: [i, j] }   // 交換
{ type: "mark",    index: i, color: 2 } // マーク付与
{ type: "unmark",  index: i }          // マーク解除
{ type: "watch",   index: i, color: 3 } // 監視インデックス更新
{ type: "done" }                        // 完了（ソート済み検査後）
```

### 4.4 音声再生機能

ソート処理に応じて音を再生する。既存版の仕様（第18章）を基本的に引き継ぐ。

- 音の高さは**配列インデックスではなく配列の値**から決まる（既存版の仕様）
- 比較 1 回につき 2 音（両辺の値）を鳴らす
- 音の長さは「遅延 × Sound Sustain」で決まる
- 同時発音数には上限を設け、超過時は最も古い音を置き換える
- 多重発音時は音量を自動的に圧縮する

### 4.5 実行制御機能

| 操作 | 内容 | 既存版の対応 |
| --- | --- | --- |
| 開始 | ソート処理を開始する | Run トグルボタン ON |
| 一時停止 | 現在の状態を保持して停止する | Run トグルボタン OFF（スレッド Pause） |
| 再開 | 一時停止位置から再開する | Run トグルボタン再 ON（スレッド Resume） |
| 停止 | 実行中の処理を中断する | 既存版に独立した停止ボタンはない（Reset が中断を兼ねる） |
| リセット | 配列を初期状態に戻す | Reset ボタン（中断 + データ再生成） |
| 再生成 | ソート対象データを生成し直す | Reset ボタン / 入力方式変更 |
| ステップ実行 | 1 操作だけ進める | Step ボタン（既存版の Stepwise モード） |
| ランダム実行 | ランダムなアルゴリズムで実行する | Random ボタン |

既存版の Reset は「実行中断」と「データ再生成」を同時に行う。Web 版では
設計書 4.5 のとおり「停止」と「リセット」を分離し、リセットは
`originalValues` への復元（配列は再生成しない）とする。データの作り直しは
「再生成」操作に割り当てる。

ボタンの有効・無効状態は、アプリケーションの状態に応じて切り替える。

### 4.6 設定機能

| 設定 | 既存版 | Web 版初期実装 |
| --- | --- | --- |
| ソートアルゴリズム | リストボックス（32種） | セレクトボックス |
| 配列の要素数 | スライダー 1〜2048（初期値 100） | 同等（上限は描画性能により調整可） |
| 配列の生成方式 | 6種類のプリセット | 同等（第16.3節） |
| アニメーション速度 | スライダー 0〜2000 → 遅延 0〜10000ms（指数） | 同等 |
| 音声の有効・無効 | Sound トグルボタン（初期 OFF） | 同等 |
| 音の持続時間 | Sound Sustain スライダー 0〜2000 → 倍率 1〜50 | 同等 |
| 音量 | **既存版には音量設定がない**（固定振幅 + 自動圧縮） | Web 版で追加（マスター GainNode） |
| Quick Sort のピボット規則 | 5種類（Quick Sort 選択時のみ表示） | Phase 2 以降で移植 |
| 統計表示（比較数・アクセス数・転倒数・ラン数） | あり（30fps で更新） | Phase 2 以降で移植 |

### 5.2 画面要素

| 要素 | 種別 | 内容 |
| --- | --- | --- |
| タイトル | 見出し | アプリケーション名 |
| アルゴリズム選択 | セレクトボックス | 使用するソート方式 |

| 要素数 | 数値入力またはスライダー | 配列のサイズ |
| 速度設定 | スライダー | アニメーション速度（遅延） |
| 音声設定 | チェックボックスまたはボタン | 音声の有効・無効 |

| 表示領域 | Canvas | 配列の可視化 |
| 開始／一時停止／停止／リセット／再生成 | ボタン | 実行制御 |
| 状態表示 | テキスト | 現在の状態やエラー |
| 統計表示 | テキスト | 比較数・アクセス数など |

### 5.3 描画方式

| 方式 | 長所 | 短所 |
| --- | --- | --- |
| DOM 要素 | 実装が分かりやすい | 要素数が多いと更新負荷が増える |
| Canvas | 大量要素を描画しやすい | 個別操作やアクセシビリティが難しい |
| SVG | 要素単位の制御がしやすい | 大量要素では負荷に注意が必要 |

既存版は wxWidgets の `wxDC` に対して棒を直接矩形描画するイミディエイトモード方式であり
（第16.6節）、要素数の上限が 2048 であることから、**Web 版は Canvas 2D を採用する**。
描画は `requestAnimationFrame` による一定間隔の再描画とし、既存版の 30fps タイマー描画に対応させる。

## 9. 処理フロー

### 9.1 初期表示

1. HTML を読み込む
2. JavaScript を初期化する
3. 初期設定を読み込む
4. 配列を生成する
5. 配列を画面に描画する
6. 操作ボタンの状態を設定する
7. 状態を「待機中」にする

### 9.2 ソート開始

1. ユーザーが開始ボタンを押す
2. 音声機能を初期化する（`AudioContext.resume()`）
3. 現在の設定を取得する
4. 配列を初期化または確認する（既存版はソート済みなら再生成する）
5. 選択されたアルゴリズムのジェネレータを生成する
6. イベントを順番に取り出す
7. 表示と音声を更新し、遅延分だけ待つ
8. すべてのイベント処理後、ソート済み検査を行い完了状態にする

### 9.3 一時停止・再開

1. 一時停止ボタンを押す
2. 現在のイベント位置（ジェネレータの状態）を保持する
3. 次のイベント処理を停止する
4. 状態を paused に変更する
5. 再開時は保持したジェネレータから処理を続行する

### 9.4 停止

1. 停止ボタンを押す
2. イベント処理をキャンセルする（実行 ID を無効化する）
3. 進行中のタイマーを解除する
4. 発音中の音を停止する
5. 状態を stopped に変更する
6. 配列表示は現状を維持する

### 9.5 リセット

1. 実行中の処理を停止する
2. `originalValues` を復元する
3. 表示状態（マーク・監視）を初期化する
4. 音声状態を初期化する
5. 統計カウンタを 0 に戻す
6. 状態を idle に戻す

## 10. エラー処理

| エラー | 対応 |
| --- | --- |
| 不正な要素数 | 許容範囲内に修正するか、メッセージを表示する |
| アルゴリズム未選択 | 開始処理を実行せず通知する（既存版も同様にエラー表示） |
| 無効な速度 | デフォルト値を使用する |
| 音声初期化失敗 | 音声なしで処理を継続する（既存版は Sound ボタンを無効化する） |
| 描画対象が存在しない | 描画処理を中断し、エラーを表示する |
| 二重実行 | 実行中は開始操作を無効化する |
| 非同期処理の競合 | 実行 ID またはキャンセルフラグで管理する |
| ソート結果が不正 | 既存版と同様、ソート済み検査で検出しエラー表示する |

音声再生に失敗しても、ソート表示機能自体は可能な限り継続する。

## 11. 非機能要件

### 11.1 操作性

- 開始、一時停止、停止、リセットの役割を明確にする
- 現在の状態を画面に表示する
- 実行中に設定が不意に変更されないようにする
- キーボードだけでも主要操作ができる構成を目指す

### 11.2 性能

- 少数から中規模（既存版と同じ最大 2048 要素）の配列を滑らかに表示できること
- アニメーション速度を変更できること
- 停止時にタイマーやイベント処理が残らないこと
- 不要な描画・DOM 更新を避けること（描画は `requestAnimationFrame` に集約する）

### 11.3 保守性

- ソートアルゴリズムと UI 処理を分離する
- 音声処理と描画処理を分離する
- アルゴリズムを追加しやすい構成にする（既存版の `g_algolist` 相当のレジストリを用意する）
- 既存版との対応関係をコメントまたは設計書に残す（第19章）

### 11.4 可搬性

- GitHub Codespaces 上で起動できること
- 静的ファイルとして配信できること
- 特定のローカル環境に依存しないこと
- 主要なモダンブラウザで動作すること

## 13. 未決事項（既存版調査による確定）

| 確認項目 | 調査結果 | 参照 |
| --- | --- | --- |
| 対応ソートアルゴリズムの一覧 | 32 種類（コメントアウトされた逐次版 Bitonic Sort を除く） | 第17章 |

### 16.3 入力データ生成方式（`SortArray::FillData`）

| # | 名称 | 内容 |
| --- | --- | --- |
| 0 | Random Shuffle | `[1, n]` をランダムシャッフル |
| 1 | Ascending | `[1, n]` の昇順 |
| 2 | Descending | `[n, 1]` の降順 |
| 3 | Shuffled Cubic | `x^3` で偏らせた値（`/3` で解像度を落とす）をシャッフル |
| 4 | Shuffled Quintic | `x^5` で偏らせた値をシャッフル |
| 5 | Shuffled n-2 Equal | 1 と n が 1 個ずつ、残り n-2 個が同値。シャッフル |

生成後に最大値を求め、マーク・監視をクリアし、比較数・アクセス数を 0 に戻す。

### 16.4 計測付き配列 API（`SortArray` / `ArrayItem`）

アルゴリズムはこの API 経由でのみ配列を操作する。これが可視化・音声・遅延の単一の入口である。

| API | 意味 | 計数 | 音 | 遅延 |
| --- | --- | --- | --- | --- |
| `A[i]` | 読み出し | アクセス | あり | あり |
| `A.get_mutable(i)` | 可変参照の取得 | アクセス | あり | あり |
| `A.get_nocount(i)` | 読み出し（アクセス計数なし） | なし | あり | あり |
| `A.set(i, v)` | 書き込み | アクセス | あり | あり |
| `A.swap(i, j)` | 交換（2 要素同時に強調表示） | アクセス x2 | あり | あり x2 |
| `A.direct(i)` | 描画用の直接読み出し | なし | なし | なし |
| `A.touch(i, color, sustain, priority)` | 一時的な色付け | なし | なし | なし |
| `A.mark(i, color)` / `mark_swap` / `unmark` / `unmark_all` | 恒久的なマーク | なし | なし | なし |
| `A.watch(&idx, color)` / `unwatch_all` | ローカル変数（`volatile ssize_t`）をインデックスとして追跡表示 | なし | なし | なし |
| 比較演算子（`<`, `<=`, `==` など）、`cmp` | 比較 | 比較数 +1 | 両辺の値で 2 音 | なし |
| `*_direct`（`less_direct` 等） | 計測なし比較 | なし | なし | なし |

同一インデックスへの連続アクセスは遅延・記録がスキップされる。
色の優先順位は `access1` > `access2` > watch > mark > access list > 通常色。

### 16.5 実行制御の挙動

| 操作 | 実装 |
| --- | --- |
| Run ON | `SortAlgoThread`（joinable な `wxThread`）を生成して実行。配列がソート済みなら実行前に再生成する |
| Run OFF | スレッドを `Pause()` する（位置を保持したまま停止） |
| Run 再 ON | スレッドを `Resume()` する |
| Step | Stepwise モードにし、セマフォで 1 アクセスぶんだけ進める |
| Reset | `m_thread_terminate` を立ててスレッドを終了させ、`FillData` でデータを再生成する |
| Random | 中断 → データ再生成 → ランダムなアルゴリズムで実行 |
| アルゴリズムのダブルクリック | 中断 → データ再生成 → そのアルゴリズムで実行 |
| 実行完了 | ワーカースレッドが `CheckSorted()` を実行し、`ID_RUN_FINISHED` イベントで Run ボタンを OFF に戻す |

遅延はワーカースレッド内の `WSortView::DoDelay()`（`wxMicroSleep`）で、
**1 回の配列アクセスごとに** 挿入される。フレーム単位ではない点が Web 移植の要点である。

### 16.6 描画

- 背景は黒。描画領域は上下左右 10px の余白付き
- 棒は下端から上方向へ、`height * value / max` の高さで描画
- 棒幅は `(width - (n-1)) / n`、棒間は 1px。幅 2px 相当の場合は特例処理
- 色は 17 色のパレット（0:白、1:赤、2:緑、3:シアン、4:黄、5:マゼンタ、以降はパステル系）
- 30fps のタイマーで `Refresh()` を呼び、`wxAutoBufferedPaintDC` にダブルバッファ描画

### 16.7 統計

| 項目 | 内容 |
| --- | --- |
| 比較数 | `g_compare_count`。`ArrayItem` の比較演算子で加算 |
| 配列アクセス数 | `g_access_count`。`SortArray::OnAccess` で加算 |
| 転倒数（inversions） | 交換時は差分更新、書き込み時は O(n^2) で再計算。アルゴリズムごとの上限（`inversion_count_limit`）超過時は "skipped" |
| ラン数（runs） | 隣接要素の降順箇所を数えて算出 |

## 18. 既存版 音声仕様

実装は `src/SortSound.cpp`（SDL 音声コールバック）および `src/WMain.cpp` の SDL 初期化部。

### 18.1 音声デバイス設定

| 項目 | 値 |
| --- | --- |
| サンプリング周波数 | 44100 Hz |
| フォーマット | 16bit 符号付き（`AUDIO_S16SYS`） |
| チャンネル数 | 1（モノラル） |
| バッファサイズ | 4096 サンプル |
| 初期状態 | 停止（`g_sound_on = false`、Sound ボタン OFF） |
| デバイス確保失敗時 | エラーログを出し、Sound ボタンを無効化（ソートは継続可能） |
| ON 切替時 | `SoundReset()` でオシレータと時刻をクリアしてから再生開始 |

### 18.2 音高の決定

配列アクセスのたびに、**アクセスした要素の値**が音源として登録される
（`SoundAccess(value)`。インデックスではない点に注意）。

```text
relative = value / array_max          // 0.0 〜 1.0
freq     = 120 + 1200 * relative^2    // 120Hz 〜 1320Hz
```

比較 1 回では両辺の値が登録されるため、2 音が同時に鳴る。

### 18.3 発音（オシレータ）

| 項目 | 内容 |
| --- | --- |
| 波形 | 三角波（`wave_triangle`）。sin / sin^3 も実装されているが未使用 |
| 音長 | `g_delay / 1000 * g_sound_sustain * 44100` サンプル（遅延 x 持続倍率） |
| 同時発音数上限 | 512。終了済みのオシレータを再利用し、空きがなければ最も古いものを置き換える |
| 発音開始時刻 | 1 コールバック内に集まったアクセスをバッファ長で等間隔に分散させる |

エンベロープは ADSR。

| 区間 | 値 |
| --- | --- |
| Attack | 音長の 2.5% |
| Decay | 音長の 10% |
| Sustain | 振幅の 90% |
| Release | 音長の 30% |

### 18.4 ミキシングと音量

- 全オシレータの出力を加算する
- 加算後の最大振幅で全体を割る（動的レンジ圧縮）
- 音量の下げ方は即時、上げ方は 1 コールバックごとに 0.9 倍のランプ
- 最終振幅は 24000 を基準にスケールし、±32200 でクリップする
- **既存版にユーザー向けの音量設定は存在しない**（Sound Sustain のみ）

### 18.5 スレッド構成

アクセスは `SoundAccess()` でミューテックス保護されたリストに積まれ、
SDL の音声コールバックスレッドが取り出してオシレータ化する。

### 18.6 Web 版での再現方針

| 既存版 | Web 版 |
| --- | --- |
| SDL コールバックで自前ミキシング | 方式1: 1 音 = `OscillatorNode`(triangle) + `GainNode` でエンベロープを `setValueCurveAtTime` / ランプで表現。方式2: `AudioWorklet` で既存版のミキシング処理を移植 |
| `g_sound_on` | `AudioContext` の状態と有効化フラグ |
| 起動時から音声デバイスを確保 | ユーザー操作時に `AudioContext` を生成し `resume()` する |
| 512 音上限・古い音の置換 | 同時発音数を制限し、超過時は最も古いノードを停止する |
| 自動音量圧縮 | マスター段に `DynamicsCompressorNode` を置く、または同時発音数で `gain` を割る |
| 音量設定なし | マスター `GainNode` を追加（Web 版独自） |

初期実装は方式1（`OscillatorNode` ベース）とし、同時発音数が多い場合の負荷が問題になれば
方式2（`AudioWorklet`）へ移行する。

### 19.2 API・概念対応

| 既存版 | Web 版 |
| --- | --- |
| `SortArray& A` を受け取るアルゴリズム関数 | `function* algorithm(array)` が操作イベントを `yield` |
| `A[i]`（読み出し + 遅延 + 音） | `yield { type: "get", indices: [i] }` |
| `A.set(i, v)` | `yield { type: "set", index: i, value: v }` |
| `A.swap(i, j)` | `yield { type: "swap", indices: [i, j] }` |
| 比較演算子（比較数 +1、2 音） | `yield { type: "compare", indices: [i, j] }` の後に値を比較 |
| `A.mark(i, c)` / `A.unmark(i)` | `yield { type: "mark" / "unmark", ... }` |
| `A.watch(&idx, c)` | `yield { type: "watch", index: idx, color: c }`（値が変わるたびに送出） |
| `A.touch(i, ...)` | 一時的な色付け。初期版では `mark` に統合してもよい |
| `g_delay`（アクセスごとの待機） | `state.delayMs`。イベント処理ごとに待機 |
| `g_sound_sustain` | `state.soundSustain` |
| `g_sound_on` | `state.soundEnabled` |
| `g_compare_count` / `g_access_count` | `state.stats.compares` / `state.stats.accesses` |
| `SortAlgoThread`（ワーカースレッド） | `async` ループ + 実行 ID によるキャンセル |
| `wxThread::Pause()` / `Resume()` | ジェネレータを保持したままループを中断・再開 |
| Stepwise + セマフォ | ステップ実行フラグ。1 イベントだけ進める |
| `CheckSorted()` | 完了時のソート済み検査 |
| 30fps の `RefreshTimer` | `requestAnimationFrame` による再描画と統計更新 |
| 17 色パレット | CSS 変数または JS の色配列（既存版と同じ RGB 値を使用） |

### 19.3 差異と非移植項目

| 項目 | 扱い |
| --- | --- |
| `std::sort` / `std::stable_sort` / `std::sort_heap` | 移植対象外（言語ランタイム依存） |
| Record ボタン | 既存版でも非表示・未実装のため対象外 |
| 転倒数の O(n^2) 再計算 | 既存版同様に上限を設ける。初期版では実装を後回しにする |
| 停止操作 | 既存版は Reset のみ。Web 版では「停止」と「リセット」を分離する |
| 音量設定 | Web 版で追加（既存版には存在しない） |
| ステップ実行 | 既存版にあり。Web 版では Phase 2 以降 |
| Quick Sort ピボット規則の UI | 既存版にあり。Web 版では Phase 2 以降 |
| アルゴリズム説明文 | 既存版の `AlgoEntry::text` をそのまま流用する（英文、必要なら和訳） |
